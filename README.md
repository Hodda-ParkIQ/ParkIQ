# ParkIQ 🚗: AI 기반 차량용 최적 주차 경로 추천 시스템

> **"단순한 주차장 검색을 넘어, 운전자의 보행 성향과 목적지 도보 거리를 고려한 초개인화 In-Car 주차 에이전트"** <br>
> 현대자동차그룹 차량용 앱 개발 공모전 (팀명: 호따 - Hodda)

<br>

## 📌 프로젝트 개요
혼잡한 도심이나 초행길에서 목적지 주변의 주차 공간을 찾기 위해 불필요하게 선회(Circling)하며 겪는 시간 소모와 연료 낭비, 그리고 이로 인한 운전자의 심리적 스트레스를 해결하기 위해 기획된 **차량 인포테인먼트 기반 스마트 주차 서비스**입니다.

기존 내비게이션의 단순 최단 거리(ETA) 안내 한계를 극복하고, **운전자의 보행 성향 및 최종 목적지(식당, 카페 등)와의 실제 도보 거리**를 복합 분석하여 최적의 주차 지점을 제안합니다.

<br>

## ✨ 핵심 기능 및 차량 특화 요소 (Core Features)

### 1. 실시간 공간 탐색 및 ETA 최소화
- 목적지 반경 2km 이내의 주차장 실시간 혼잡도 및 교통 상황을 정밀 분석하여 최소 주차 ETA 경로를 제공합니다.

### 2. 플레오스(Pleos) 인포테인먼트 연동
- 현대차·기아의 차세대 인포테인먼트 플랫폼 환경에 맞춰 운전 중 주행 시선 분산을 최소화하는 직관적인 원터치 UI 및 음성 안내(Voice UI)를 지원합니다.

### 3. 초개인화 주차 추천 알고리즘
- 차량 ETA가 더 빠른 주차장 대신, 예약된 목적지와의 도보 거리가 훨씬 가까운 주차장을 우선 추천하는 등 사용자 맞춤형 도보 동선 최적화를 제공합니다.

<br>

## 🗺️ 주요 사용 시나리오
1. **목적지 설정**: 차량 내 플레오스 인포테인먼트 화면을 통해 방문할 목적지(예: 식당)를 설정합니다.
2. **다차원 분석**: 시스템이 주변 주차장 리스트와 함께 '식당까지의 도보 이동 거리' 및 '주차장 만차 위험도'를 동시 연산합니다.
3. **원터치 경로 등록**: 디스플레이에 팝업된 최적의 주차장을 원터치로 선택하여 곧바로 경로의 경유지로 등록하고 주차 스트레스 없이 도달합니다.

<br>

## ⚙️ 시스템 아키텍처 및 개발 계획 (Tech Stack & Architecture)

### Frontend (In-Car UI/UX)
- **Pleos Connect SDK**: 현대차그룹 Pleos Connect 환경에 맞춘 차량용 웹 프레임워크 기반 UI 구현
- **Voice UI**: Gleo AI 음성 명령어 연동을 통한 핸즈프리 조작 모듈 개발

### Backend & Data Pipeline
- **Framework**: Python (`FastAPI`) 기반 고성능 백엔드 API 서버
- **Database**: `PostgreSQL` + `PostGIS`를 활용한 공간 데이터(Geospatial Data) 고속 연산 및 인덱싱
- **API Integration**: 공공데이터포털 실시간 주차장 정보 API 및 민간 주차 플랫폼 연동

### 알고리즘
- **Multi-objective Optimization**: 차량 이동 소요 시간(ETA)과 목적지 도보 이동 시간을 동시에 최소화하는 다목적 최적화 가중치 알고리즘 적용

<br>

## 🚀 향후 발전 가능성 (Future Expansion)
- **전기차(EV) 및 스마트 인프라 연동**: 충전 속도, 주변 편의시설, 도보 거리를 통합 고려한 전기차 맞춤형 스마트 주차·충전 통합 솔루션 고도화
- **자동차 타임라인 기반 장소 추천 확장**: 운전자의 실시간 일정, 누적 주행 패턴, 차량 상태를 연계하여 시간대별 맞춤 장소를 선제적으로 제안하는 모빌리티 라이프 에이전트로 확장
